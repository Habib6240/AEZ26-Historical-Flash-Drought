# Changelog

- Added `scripts/detection/AEZ26_SI_verify_matching_v04.py`: standalone check that the greedy one-to-one matching used for the onset-agreement counts equals a maximum one-to-one matching (6 observed and 75 year-shifted comparisons; also referenced from Supplementary Text S1.3). - Metadata: the manuscript title cited in `README.md`, `CITATION.cff` (abstract) and `.zenodo.json` (description) now reads "Source-dependent flash-drought chronology and land–water responses in the High Barind Tract, Bangladesh, 2000–2025" (previously an earlier working title). The record titles of this software release are unchanged.
- No analysis code, notebook, equation, threshold, stored output or scientific result was changed. `QA_REPORT.md` and `qa_results.json` record the v1.0.1 QA run and were not regenerated. The derived-dataset record (v1.0.1) is unchanged.
