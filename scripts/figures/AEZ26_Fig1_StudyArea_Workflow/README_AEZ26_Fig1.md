# AEZ-26 Fig. 1 (v05)
Panel a: study-area map (WGS 84 / UTM zone 45N, EPSG:32645) with a straight, evenly spaced 10 km UTM grid (easting/northing in km; geographic coordinates as ticks on the top and right edges), a scale bar, a grid-north arrow and a Bangladesh locator inset. Panel b: workflow of the historical study (the earlier CMIP6 branch was removed). v05 corrects the v04 figure, in which lon/lat graticule lines drawn on the UTM map looked tilted because of grid convergence (about 0.6 degrees at the study-area centre); projection, geometry and content are unchanged. The approved caption is in `AEZ26_Fig1_Caption.txt`.
Run `python make_AEZ26_Fig1_v05.py --out-dir DIR` (needs `geo.py`, matplotlib, numpy, Pillow). The script needs `data/AEZ26_HBT_boundary_recovered.geojson` and `data/BGD_locator_outline_recovered_simplified.json` next to it; both are **not redistributed** (the national outline derives from GADM, which does not permit redistribution; redistribution rights for the BARC-derived AEZ-26 geometry are not verified). The plotted AEZ-26 coordinates were recovered from the vector paths of an earlier figure version and agree with the Earth Engine export of the study-area polygon to within 3e-9 degrees (checked in the author's workspace); replace the file with the original export to regenerate the figure. In the author's workspace the script reproduces the released `figures/AEZ26_Fig1_StudyArea_Workflow.png` (v05) pixel-identically; **not run in this repository test**. See `metadata/FIG1_PROVENANCE.md`.
