# Detection
`independent_detector_and_chronology_audit.py` is an independent Python re-implementation of the first-crossing detector of Section 3.1. It reproduces the stored 39-event GLDAS catalogue and the stored ERA5-Land OVERLAP26 catalogue exactly (asserted in the script) and then runs the chronology audit (Sections 3.4, 4.2). The original Phase 2C v3 notebook that produced the catalogue is in `notebooks/`; this script is an independent re-implementation and not the original code. Run: `python3 -I scripts/detection/independent_detector_and_chronology_audit.py` from any directory.

`AEZ26_SI_verify_matching_v04.py` (added in v1.0.2) checks that the greedy one-to-one matching used for all onset-agreement counts (Section 3.3) gives the same counts as a maximum one-to-one matching. It compares 6 observed and 75 year-shifted cases (81 comparisons) for the primary, OVERLAP26 and LONG45 catalogues, uses an augmenting-path matching and, if SciPy is installed, SciPy's maximum bipartite matching, and exits with status 1 if any count differs from the documented value. It reads only the three released catalogue files; run `python3 -I scripts/detection/AEZ26_SI_verify_matching_v04.py` with the dataset's `data/` folder next to `scripts/` (or pass `--dataset-root`). It does not change any analysis output. The same file is provided in the Supplementary Information (`Code/`).
