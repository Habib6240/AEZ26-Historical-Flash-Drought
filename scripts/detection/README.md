# Detection
`independent_detector_and_chronology_audit.py` is an independent Python re-implementation of the first-crossing detector of Section 3.1. It reproduces the stored 39-event GLDAS catalogue and the stored ERA5-Land OVERLAP26 catalogue exactly (asserted in the script) and then runs the chronology audit (Sections 3.4, 4.2). The original Phase 2C v3 notebook that produced the catalogue is in `notebooks/`; this script is an independent re-implementation and not the original code. Run: `python3 -I scripts/detection/independent_detector_and_chronology_audit.py` from any directory.
